# URL Shortener

A URL Shortener REST API built with Spring Boot and Java.

## Tech Stack

- Java 25
- Spring Boot
- PostgreSQL
- Redis
- Docker
- Flyway
- Gradle
- JUnit
- Mockito
- Testcontainers

## Features

- Create short URLs
- HTTP 302 redirects
- PostgreSQL persistence
- Redis caching
- Cache-Aside pattern
- URL expiration
- Redis TTL
- Click counter
- Global exception handling
- Unit and integration tests
